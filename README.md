## 🚀 部署與本地運行 (Deployment & Usage)

### 本地預覽
直接在瀏覽器中開啟 `index.html`，或使用 VS Code Live Server 插件進行本地預覽。

### 啟用 GitHub Pages 免費託管
1. 將專案推送到 GitHub 倉庫：`https://github.com/waiyanchan0519/mynewproject`
2. 進入倉庫的 **Settings** -> **Pages**。
3. 在 **Build and deployment** 下的 **Branch** 選擇 `main` 分支與根目錄 `/ (root)`。
4. 點擊 **Save**，幾分鐘後即可透過專屬網址上線訪問！
